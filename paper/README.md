# Gen-Retry Manuscript Workspace

This directory is reserved for the project's own future manuscript, figures,
tables, supplementary material, and bibliography. It is not an external-PDF
archive.

External papers belong in the `references/` inventory, with claim-level
grounding in `docs/SOURCE_LEDGER.md` and project-specific interpretation in
`docs/research/`. Keeping that separation prevents a downloaded related-work
paper from being confused with Gen-Retry-authored material.

No manuscript source has been added yet. If the paper later becomes a
cross-repository project, create a separate manuscript repository through an
explicit repository-boundary decision; do not move it into the shared parent
directory beside multiple legacy implementations.
